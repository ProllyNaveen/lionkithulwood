FOR EACH PRODUCT, YOU NEED:
================================================================================

1. MAIN IMAGE (required)
   File: {product-id}.jpg
   Location: /images/products/
   Example: /images/products/spoon-set.jpg

2. PRODUCT FOLDER (optional but recommended)
   Folder name: {product-id}/
   Location: /images/products/{product-id}/
   Example: /images/products/spoon-set/
   
   Inside this folder:
   - detail-1.jpg
   - detail-2.jpg
   - lifestyle.jpg
   - closeup.jpg
   (any images you want to show)

================================================================================
STEP-BY-STEP INSTRUCTIONS
================================================================================

Step 1: Keep Main Images
The main product images are already at:
/images/products/{product-id}.jpg
Example: /images/products/spoon-set.jpg

DO NOT MOVE OR DELETE THESE!

Step 2: Create Product Folders
Using your file manager or command line:

mkdir /images/products/spoon-set/
mkdir /images/products/mortar-pestle/
mkdir /images/products/cutting-boards/
... (repeat for all products)

Step 3: Add Extra Images
Copy your additional product photos into the folders:

/images/products/spoon-set/
├── detail-1.jpg
├── detail-2.jpg
└── lifestyle.jpg

Step 4: Done!
Your website will automatically show these images in the product detail page!

================================================================================
IMAGE REQUIREMENTS
================================================================================

Format: JPG, PNG, or WebP
Size: Ideally 1200px × 1200px or larger (square aspect ratio works best)
Quality: High quality (natural lighting, clear product visibility)
Naming: Use simple names (detail-1.jpg, angle-2.jpg, lifestyle.jpg)

================================================================================
WHAT HAPPENS WHEN YOU ADD IMAGES
================================================================================

1. User visits your homepage
2. User clicks on a product card
3. Product detail page loads with:
   ✓ Main product image
   ✓ Thumbnail gallery of additional images (if you added any)
   ✓ Full product description
   ✓ Size and material info
   ✓ Product features
   ✓ WhatsApp inquiry button

================================================================================
OPTIONAL: Product Folders ARE NOT Required
================================================================================

✓ Your website works with JUST the main image
✓ Creating product folders is OPTIONAL for better presentation
✓ Start simple, add detailed images later!

================================================================================
EXAMPLE: SPOON-SET PRODUCT
================================================================================

Currently you have:
/images/products/spoon-set.jpg

To add more images, create:
/images/products/spoon-set/

Then add images like:
/images/products/spoon-set/detail-close.jpg
/images/products/spoon-set/set-display.jpg
/images/products/spoon-set/in-kitchen.jpg

When someone clicks "Kithul Wood Spoon Set" on your homepage:
→ They'll see the main image
→ A gallery of your 3 detail images appears below
→ They can click thumbnails to switch images
→ All product info displays beautifully
