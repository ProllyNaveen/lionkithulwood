📋 Instructions

  1. Fill out the form above with your product details
  2. Click "Add Product to JSON" - it generates JSON code
  3. Copy the generated JSON (shown below)
  4. Edit data/products.json in your text editor and paste before the closing bracket
  5. Upload the updated file to your server
  6. Create image folder at /images/products/{product-id}/ and upload pic1.jpg, pic2.jpg, etc.
  7. Refresh your website - new product appears!
