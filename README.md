# Lion Kithul Wood - Website

A static website for Lion Industries, showcasing hand-crafted wooden products from Sri Lanka.

## Tech Stack

- **HTML5** - Structure
- **CSS3** - Styling & Responsive Design
- **JavaScript** - Interactive features (carousel, product filtering)
- **JSON** - Product data management
- **GitHub Pages** - Hosting

## Features

- Responsive design (mobile, tablet, desktop)
- Dynamic product catalog (loads from `data/products.json`)
- Image carousel in "Our Story" section
- Product detail pages with image galleries
- WhatsApp integration for inquiries
- Custom .lk domain support
